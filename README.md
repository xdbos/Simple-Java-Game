# 2D Coin collection game

## Description
First ever JAVA project, contains a really simple movement and collision system (should note that I know the collision system is definitely not ideal). 
It also contains a map editor that allows for map loading/saving.
The maps are 20 by 20 tiles big.

## How to play
In the main menu select one of three maps by pressing "1", "2" or "3" on your keyboard.
Once inside a level you need to collect all the gold chests and get back to the exit to win.

## Controls

###Main menu
* Press "1", "2" or "3" to play a premade(but overridable level).
* Press "e" to enter the map editor.

###Game
* Use w, a, s, d to move the player around.
* Press "m" to go back to the main menu.

###Editor
* Use w, a, s, d to move the map.
* Press "-" to zoom the map out and "=" to zoom the map in.
* Press "q" to load any map named "data.csv" into the editor.
* Press "r" to reset the map editor (delete the current map).
* Press "e" to save any changes to the map to "data.csv".
* Press "1", "2" or "3" to save any created map over the existing 3 maps.
* Press "m" to go back to the main menu.
